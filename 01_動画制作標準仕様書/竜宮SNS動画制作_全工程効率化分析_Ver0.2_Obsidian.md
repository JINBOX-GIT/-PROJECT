# 竜宮SNS動画制作・全工程効率化分析

## 1. 目的

竜宮六姫のInstagram Reels制作について、企画から投稿後の分析までの全工程を対象に、以下を整理する。

1. すでに効率化できた工程
2. 制作仕様として標準化できた工程
3. 今後ChatGPT Work等で効率化できる工程
4. 制作本数を週2本から週4本へ増やすための改善施策
5. 制作品質を維持しながら生産性を向上させる方法
6. 六姫全員の多方向基準画を共通制作資産として整備する方法

本分析では、単純な作業時間の削減だけでなく、再生成の削減、手戻り防止、制作ノウハウの再利用、品質管理、クレジット消費、投稿後分析も対象とする。

## 2. 現在の制作体制

| ツール | 担当する役割 |
|---|---|
| Chatty | 企画、演出、プロンプト、仕様作成、分析、改善提案 |
| ChatGPT Work | 複数工程の実行、制作素材の整理、中間静止画制作支援、成果物作成 |
| FlovaAI | 動画生成AIの利用、動画生成、モデル選定・制作支援 |
| Vidu / Seedance等 | 実際の動画生成モデル |
| CapCut | 映像編集、CUT接続、音声、字幕、最終書き出し |
| Obsidian | 企画、制作仕様、制作記録、ノウハウの蓄積 |
| GitHub | Markdown文書の正本・履歴管理、Chattyからの直接更新 |
| OneDrive | Windows側の制作資料・Obsidian Vaultの母艦 |
| Instagram | Reels公開、視聴者への配信 |
| Metricool | Instagramの実績分析、投稿データ管理 |

※ 各ツールの機能・連携状況によって、自動実行できる範囲は異なる。

- 音姫・光姫の仕様書はGitHubリポジトリ内の「ビジュアル仕様書」フォルダで管理されているとの報告を受けている。
- この分析では両仕様書のGitHub本文・画像成果物を直接検証していないため、全方向の完成や承認を推定しない。
- 光姫の制作計画では、正面0°を原本固定とし、左右15°・45°・90°・背面180°を含む計8方向を管理する。
- 海姫には過去の3方向制作経験があるが、それをそのまま8方向の完成実績とは扱わない。

#### 3.3.2 六姫全員へ展開する理由

多方向基準画は、各CUTで斜め顔・横顔・背面を毎回推定する負荷を下げ、キャラクターのIdentity・Geometry・Costumeを比較するための共通制作資産となる。期待される効果は、基準画の再利用、生成前の参照画像準備短縮、動画QAの判断基準統一、再生成・手戻り削減である。

ただし、動画生成モデルが複数参照画像をどの程度利用できるかはモデル別に検証する。基準画が存在するだけで動画のIdentity Driftが解消するとは断定しない。

#### 3.3.3 六姫共通テンプレートの展開手順

1. 音姫・光姫のVer0.1を比較し、制作工程・方向ID・QA・成果物の共通要素を抽出する。
2. 各姫の顔・髪・衣装・装飾は個別の正式基準画・上位仕様を参照し、外見設定そのものは共通化しない。
3. 六姫共通のWork依頼テンプレートを作成する。
4. 海姫を次の検証候補とし、既存3方向制作の知見を利用する。
5. 月姫・星姫・天姫へ順次展開する。実際の制作順は投稿計画・素材の準備状況で決定する。
6. 各方向の生成・QA・承認・再生成履歴を管理する。背面など未確定の推定箇所は承認前に正式設定へ昇格させない。

#### 3.3.4 動画制作への再利用フロー

```text
正式正面基準画・キャラクター仕様
  ↓
Workによる多方向基準画の制作・QA
  ↓
制作者が方向別に承認
  ↓
承認済み画像を制作資産として管理
  ↓
CUTの構図・動作に合う方向画像を選択
  ↓
Start / End・中間静止画制作に活用
  ↓
FlovaAIの対応機能に応じて参照・動画生成
  ↓
動画QA・再利用効果を測定
```

## 7. 制作時間の削減シミュレーション

仮に従来、1本当たり10時間を要していた場合の例。

| 工程 | 従来 | 改善目標 |
|---|---:|---:|
| 企画・構成 | 1.5時間 | 0.5時間 |
| 台本・プロンプト | 1.5時間 | 0.5時間 |
| 画像・素材制作 | 2.0時間 | 1.0時間 |
| FlovaAI動画生成・再生成 | 2.5時間 | 1.5時間 |
| 編集・最終QA | 1.5時間 | 1.0時間 |
| 投稿・記録 | 1.0時間 | 0.5時間 |
| **合計** | **10時間** | **5時間** |

これは目標設計用の仮定値であり、実測結果ではない。

20時間の週間制作枠を仮定した場合：

```text id="o6d22u"
従来
10時間 × 2本 = 20時間

改善後
 5時間 × 4本 = 20時間
```

## 8. 週4本を実現する制作方式

### 8.1 企画・準備のバッチ処理

4本を1本ずつゼロから制作するのではなく、共通作業をまとめる。

```text id="39k58o"
週次企画
   ↓
4本分のテーマ確定
   ↓
4本分の構成・台本を作成
   ↓
4本分のCUT設計
   ↓
承認済み多方向基準画を含む共通素材を準備
   ↓
各動画の生成
   ↓
編集・QA
   ↓
投稿・実績記録
```

共通工程と承認済み多方向基準画の再利用によって、毎回の準備負荷を下げる。

### 8.2 動画の難易度を組み合わせる

週4本すべてを複雑な変身動画にする必要はない。

制作負荷を考慮して組み合わせる。

| 動画区分 | 週の本数例 | 特徴 |
|---|---:|---|
| 高難度 | 1本 | 光の生物・衣装変身等 |
| 中難度 | 1本 | 六姫の演技・会話等 |
| 低〜中難度 | 2本 | キャラクター紹介・短尺演出・派生版等 |
| 合計 | 4本 | 品質と制作負荷のバランス |

これは制作計画の提案であり、作品内容の正式な決定ではない。

### 8.3 再生成回数の削減

動画制作で時間とクレジットを消費する大きな要因の一つは、意図しない生成結果の修正である。

そのため、以下を重点的に改善する。

1. 生成前の仕様確認
2. 基準画像のQA（必要に応じて多方向基準画との照合）
3. Start / End状態の確定
4. 動画生成モデルの適切な選定
5. 生成前のプロンプトレビュー
6. NG原因の切り分け
7. 部分修正・後編集の優先
8. 同一失敗の再発防止
