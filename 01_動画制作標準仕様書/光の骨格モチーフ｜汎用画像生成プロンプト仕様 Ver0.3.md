# 光の骨格モチーフ｜汎用画像生成プロンプト仕様 Ver0.3

## 1. 制作目的

任意の生物をモチーフとして、**光の粒子と極細の電流状発光フィラメントによって、立体的な骨格が形成されている途中段階**を描く。

完成した生物の身体を発光させるのではなく、光そのものが生物の形状を構成している状態とする。

光姫のイルミネーション演出において、光の粒子が集合し、任意の生物の姿へ変化する途中段階のビジュアルとして利用する。

本仕様は、クリオネ・蝶・イルカ・龍・鳥・魚など、異なる生物に共通して使用できる画像生成プロンプトとする。

## 2. モチーフ指定

### 2.1 入力パラメータ

画像生成時に、以下を指定する。

| パラメータ                 | 内容        | 指定例          |
| --------------------- | --------- | ------------ |
| \`MOTIF\`               | 対象となる生物   | クリオネ、蝶、イルカ、龍 |
| \`REFERENCE_IMAGE\`     | 生物の形状基準画像 | 添付画像、または指定なし |
| \`ORIENTATION\`         | 生物の向き     | 正面、側面、斜め45°  |
| \`POSE\`                | 姿勢・動作     | 静止、遊泳、飛翔     |
| \`COLOR_PALETTE\`       | 光の基本色     | 青紫・青・ピンク・白   |
| \`LIGHT_CORE_POSITION\` | 光の核の位置    | 胴体中央、頭部、指定なし |

指定がない場合は、以下を標準条件とする。

- 向き：正面
- 姿勢：生物の特徴が分かる自然な姿勢
- 色彩：青紫・バイオレット・ブルー・ピンク・白色光
- 背景：完全な黒
- 画面比率：9:16
- 光の核：生物の形状に応じた自然な位置

### 2.2 モチーフ形状の優先原則

**生物の形状は、指定されたモチーフまたは添付の形状基準画像に従う。**

以下を維持する。

- 生物固有の頭部形状
- 胴体の形状と比率
- 手足・翼・ヒレ・触角・尾など、実際に存在する部位
- 各部位の位置関係
- 生物固有のシルエット
- 指定された姿勢と向き

存在しない部位を勝手に追加しない。

例えば、イルカに翼を追加したり、蝶にクリオネの尾を追加したりしない。

実在生物はその特徴的な形態を尊重し、架空生物は指定されたデザインに従う。

## 3. ビジュアルコンセプト

### 3.1 基本コンセプト

**「微細な電流が流れる蜘蛛の巣状の極細光フィラメントによって形成された、未完成の生物」**

以下の5要素を共通表現として使用する。

1. **光の骨格（Luminous Skeleton）**\
   対象生物の立体構造を、極細の発光フィラメントによって形成する。
2. **電流状の発光線（Electrical Filaments）**\
   光の線は均一な実線ではなく、微細な電流が流れるように不規則に明滅する。
3. **蜘蛛の巣状の網目（Web-like Mesh）**\
   無数の極細発光フィラメントが交差・分岐し、立体的な網目構造を形成する。
4. **光の粒子（Luminous Particles）**\
   骨格の内部と周辺に無数の微細な光粒子が浮遊する。
5. **未完成の身体（Incomplete Formation）**\
   対象生物の外形は認識できるが、身体表面はまだ形成されていない。

### 3.2 光の骨格の基本原則

**生物の立体形状は、太い輪郭線ではなく、極細フィラメントの集合と光粒子の密度によって表現する。**

光の骨格は、硬いワイヤーフレームではなく、繊細な光糸が複雑に結びついた透明な立体構造とする。

## 4. 形状仕様

### 4.1 頭部

頭部を持つ生物の場合、以下を適用する。

- 対象生物固有の頭部形状を維持する。
- 目・口・鼻・触角などは、対象生物に存在する場合のみ表現する。
- 頭部の輪郭は無数の極細発光フィラメントによって形成する。
- 目がある場合は、その位置に小さな発光点を配置できる。
- 頭部内部は透明な網目構造とする。
- 完成した皮膚・鱗・毛皮などの質感は描かない。
- 頭部の外周を太い連続光で囲まない。

頭部のない生物、または頭部が明確でない生物では、無理に頭部を追加しない。

### 4.2 胴体・中心構造

- 対象生物固有の胴体形状を維持する。
- 胴体内部に複雑な立体網目を形成する。
- 光の核を配置する場合は、指定位置または自然な位置に配置する。
- 光の核から極細の電流状フィラメントが各部位へ広がる。
- 光の核から太い主幹線を形成しない。
- 身体表面は透明で、内部の光の構造が見える状態とする。
- 胴体の立体感は光粒子の密度と発光輝度によって表現する。

### 4.3 翼・ヒレ・四肢・触手など

対象生物に存在する部位のみ描く。

- 部位固有の形状と大きさを維持する。
- 極細発光フィラメントが部位の構造に沿って広がる。
- 発光フィラメント同士を蜘蛛の巣状の網目で接続する。
- 表面は透明で、光線と粒子を中心に構成する。
- 外縁は部分的に途切れていてもよい。
- 実体のある羽毛・膜・皮膚などはまだ形成しない。
- 翼やヒレの外周を太い発光線で強調しない。

### 4.4 尾部・末端構造

対象生物に尾部や細長い末端構造が存在する場合に適用する。

- 対象生物固有の尾部形状を維持する。
- 複数の極細フィラメントが交差・分岐しながら末端へ伸びる。
- 光線は立体的な網目構造を形成する。
- 先端の形状は対象生物に従う。
- 完成した滑らかな表面は描かない。
- 尾部の輪郭を太いネオン状の光線にしない。

尾部のない生物には適用しない。

## 5. 光の線の表現

### 5.1 最重要仕様｜極細発光フィラメント

**光の線を、固定されたワイヤーフレームではなく、内部に微細な電流が流れている極細の発光フィラメントとして描く。**

具体的には以下の特徴を持たせる。

- 骨格を構成する光の線は、髪の毛よりも繊細に見える極細の発光フィラメントとする。
- 光の線の太さは、極細の範囲内でのみ微妙に変化させる。
- 太い主幹線、強い輪郭線、連続したネオン状の外周線は形成しない。
- 生物の外形は、無数の極細フィラメントと光粒子の密度によって認識させる。
- 微細な電流はフィラメントの内部を流れ、局所的に明滅する。
- 線の途中に明るい部分と暗い部分が存在する。
- 微細な稲妻のような揺らぎを含むが、太い稲妻状の放電にはしない。
- 線の交差点では小さな光粒子が強く輝く。
- 線の一部は途切れ、光粒子へ分解される。
- 網目の形状は幾何学的だが、完全に規則的ではない。
- 発光線は対象生物の立体形状に沿って配置する。
- 光の核から伸びる線も、周囲と同じ極細フィラメントで構成する。
- 明るさの強弱は、線幅を太くするのではなく、発光輝度と粒子密度の変化によって表現する。
- 蜘蛛の巣よりも繊細な光糸が、複雑に交差して生物の立体構造を形成する。

**最重要：光の線は極細のまま維持し、輪郭線を太くして形状を強調しないこと。**

### 5.2 避けるべき表現

- 均一な太さのネオン管
- 固定された金属ワイヤー
- 完全に整列したポリゴンメッシュ
- 単純なCGワイヤーフレーム
- 太く硬いレーザー光線
- 太い稲妻状の放電
- 太い主幹線
- 強く連続した外周輪郭線
- 完成した身体の輪郭だけを発光させる表現
- 線幅を太くすることで明るさを強調する表現

### 5.3 線幅と発光輝度の分離

線幅と発光輝度は、別の要素として制御する。

- 線幅：極細の範囲を維持する。
- 発光輝度：線の途中で強弱をつける。
- 光粒子密度：部位によって変化させる。
- 網目密度：生物の立体形状に合わせて調整する。
- 光の核：周辺より明るくできるが、太い光線の発生源にはしない。

**高輝度の発光部分であっても、線そのものを太くしない。**

## 6. 光粒子の表現

- 微細な光粒子を骨格内部に多数配置する。
- 粒子の大きさと明るさに変化をつける。
- 発光線の交差点には比較的明るい粒子を配置する。
- 粒子の一部は線から離れて浮遊する。
- 粒子が集合して骨格を形成している印象を与える。
- 光粒子の密度によって身体の立体感を補強する。
- 骨格の外側に巨大な銀河や星雲を形成しない。

**銀河的な輝きは対象生物の身体内部に限定する。**

## 7. 色彩仕様

### 7.1 標準色

基本色：

- 青紫
- バイオレット
- ブルー
- ピンク
- 白色光

補助色：

- 淡いゴールド
- 暖色系の微細な発光点

### 7.2 色彩変更

モチーフに応じて色彩を変更できる。

ただし、以下は共通条件とする。

- 発光線と光粒子によって色彩を表現する。
- 身体全体を単一色で塗りつぶさない。
- 色彩を変更しても、透明な光の骨格構造を維持する。
- 光の核と発光線の色彩に自然な連続性を持たせる。
- 高輝度部分であっても、線幅を太くしない。

## 11. 制作段階の定義

本仕様は、以下の形成過程のうち\*\*第3段階「光の骨格形成」\*\*に相当するビジュアルを制作する。

| 段階       | 状態         | 表現                                  |
| -------- | ---------- | ----------------------------------- |
| 第1段階     | 光粒子        | 粒子が浮遊する                             |
| 第2段階     | 光線発生       | 粒子同士が極細の電流状フィラメントで接続される             |
| **第3段階** | **光の骨格形成** | **蜘蛛の巣状の極細発光フィラメントが対象生物の立体形状を構成する** |
| 第4段階     | 身体形成       | 骨格に光の膜や質感が加わる                       |
| 第5段階     | 完成体        | 対象生物の身体が完成する                        |

※この5段階は画像生成のための制作上の分類案であり、正式設定への追加を意味しない。

## 12. 品質検査基準

生成結果について、以下を確認する。

- 指定された生物の形状が認識できる。
- 指定された向き・姿勢になっている。
- 対象生物固有のシルエットが維持されている。
- 対象生物に存在しない部位が追加されていない。
- 身体が透明な光の骨格で構成されている。
- 蜘蛛の巣状の立体網目が存在する。
- 光の線が極細の発光フィラメントになっている。
- 線の太さの変化が極細の範囲内に収まっている。
- 光の線に微細な電流状の揺らぎがある。
- 太い主幹線が存在しない。
- 太い稲妻状の放電が存在しない。
- 強く連続した外周輪郭線が存在しない。
- 発光輝度と粒子密度によって立体感が表現されている。
- 微細な光粒子が十分に存在する。
- 光の核が指定条件に従っている。
- 身体表面が完成していない。
- 巨大な銀河が骨格の外に存在しない。
- 黒背景、9:16縦長構図を維持している。

## 13. 最重要指示

**「完成した生物を光らせる」のではなく、「光の粒子と微細な電流が蜘蛛の巣状に結びつき、指定された生物の立体的な骨格を形成している状態」を描くこと。**

光の線は、硬いワイヤーフレームではなく、微細な電流が流れる生きた極細発光フィラメントとして表現する。

**モチーフの形状は変更可能だが、極細の光の骨格・微細な電流・蜘蛛の巣状の網目・光粒子という表現技術は維持する。**

生物の外形は、太い輪郭線ではなく、極細フィラメントと光粒子の密度によって形成する。

**光の明るさを強くする場合でも、線幅を太くしない。**

身体の実体化はまだ行わない。
