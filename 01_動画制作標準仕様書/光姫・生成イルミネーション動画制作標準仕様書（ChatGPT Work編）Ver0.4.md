# 光姫・生成イルミネーション動画制作標準仕様書（ChatGPT Work編）Ver0.4

## 1. 目的

本仕様書は、光姫が理想鏡ルミアを起動し、光の粒子から対象モチーフのイルミネーションを創造する10秒間の演出について、ChatGPT Workによる静止画制作工程を標準化する。

開始基準画と終了基準画の2枚を入力し、Workがその間の演出を設計して、1秒刻みの中間静止画9枚を一括生成する。

今回のクリオネ制作で成功した「光の骨格形成表現」を共通技術として取り込み、イルカ・蝶・クラゲなど、異なるモチーフでも再利用できる制作手順を確立する。

本仕様書の目的は、6秒時点の骨格画像だけを単独制作することではない。

**10秒間の連続した光イルミネーション形成演出を、9枚の中間静止画として制作することが目的である。**

## 2. 適用範囲

### 2.1 対象

- キャラクター：光姫
- 専用アイテム：理想鏡ルミア
- 映像表現：光イルミネーション生成
- 対象モチーフ：制作ごとに指定
- 制作時間軸：T0〜T10
- 静止画間隔：1秒
- 画像比率：縦9:16
- 制作ツール：ChatGPT Work

### 2.2 モチーフ共通化

本仕様書は、特定の生物・物体の形状に依存しない。

対象モチーフの頭部、胴体、翼、ひれ、触角、尾などの構造は、完成基準画を解析して抽出する。

クリオネ制作で得た光骨格の表現技術は再利用するが、クリオネ固有の形状を他のモチーフに転用してはならない。

### 2.3 上位仕様との関係

本仕様書はSNS動画制作における個別工程仕様であり、作品の正式設定やキャラクターの確定仕様を変更するものではない。

キャラクターのIdentity・Geometry・衣装・装飾・専用アイテムの確定事項については、上位設定およびMIXXIAビジュアル制作仕様書を優先する。

設定の不一致が判明した場合、Workが独自に設定を修正してはならない。

## 3. 制作体制・役割分担

### 3.1 制作者

- 制作モチーフを決定する。
- 開始基準画・終了基準画を指定する。
- 制作方針を承認する。
- Workが一括制作した成果物を最終確認する。
- 採用・不採用・再制作を決定する。

### 3.2 Chatty

- 制作目的と演出意図を整理する。
- Workへの一括制作依頼を設計する。
- 仕様書・品質基準・禁止事項を管理する。
- Workの成果物に対する評価と改善を支援する。

### 3.3 ChatGPT Work

- 開始・終了基準画を解析する。
- 10秒間の演出と各秒の変化を設計する。
- T1〜T9の9枚を時系列順に生成する。
- 各画像を自己点検し、必要に応じて修正・再生成を試みる。
- 全体の時間的連続性を検査する。
- 成果物とQAレポートをまとめて提出する。

Workによる自己点検は、人物の同一性や連続性を完全に保証するものではない。

## 4. 入力仕様

### 4.1 必須入力画像

**添付①：開始基準画（T0）**

理想鏡ルミアが起動する時点の光姫の画像。

**添付②：終了基準画（T10）**

対象モチーフの光イルミネーションが完成した時点の画像。

画像入力は原則としてこの2枚のみとする。

T1〜T9の中間画像は入力時点では存在しない。

### 4.2 制作パラメータ

| パラメータ     | 指定内容      |
| --------- | --------- |
| 対象モチーフ    | ［モチーフ名］   |
| 開始時点      | T0        |
| 終了時点      | T10       |
| 生成対象      | T1〜T9     |
| 生成枚数      | 9枚        |
| 画像比率      | 9:16      |
| 骨格形成の基準時点 | T6        |

### 4.3 入力画像の優先順位

- 人物の同一性：正式なキャラクター仕様と承認済み基準画を優先する。

- 開始状態：添付①を基準とする。
- 中間動作：両画像をもとに自然な動きを設計する。
- 背景：両画像に共通する空間構造を維持する。

## 5. 10秒間の標準演出設計

### 5.1 基本時間軸

| 時点     | 演出段階                 | 制作              |
| ------ | -------------------- | --------------- |
| T0     | ルミア起動                | 添付①             |
| T1     | 光の発生                 | 新規生成            |
| T2     | 光粒子の集積               | 新規生成            |
| T3     | 光の軌跡が形成される           | 新規生成            |
| T4     | モチーフの輪郭が現れ始める        | 新規生成            |
| T5     | 光の構造線・骨格形成が進行        | 新規生成            |
| **T6** | **モチーフを識別できる光の骨格形成** | **新規生成・重点品質確認** |
| T7     | 骨格に光の面・粒子が集まり実体化開始   | 新規生成            |
| T8     | イルミネーションの密度と輝きが増加    | 新規生成            |
| T9     | 完成直前                 | 新規生成            |
| T10    | 光イルミネーション完成          | 添付②             |

上記は標準時間軸である。

モチーフごとの動きや発光表現は調整できるが、骨格形成の基準時点は原則T6とする。

### 5.2 形成進行の原則

T1〜T10において、モチーフの構造完成度は原則として一方向に進行させる。

T5で完成したモチーフが現れ、T6で未完成の骨格に戻るような逆行を禁止する。

ただし、光粒子の一時的な拡散、明滅、光の揺らぎなど、完成度の逆行を伴わない演出は許可する。

### 5.3 骨格形成と実体化の区別

- T5以前：光の構造が組み上がる段階。
- T6：モチーフを認識できる光骨格が成立する段階。
- T7以降：成立した光骨格を基礎として光の面・密度・質感が増していく段階。

**骨格形成と実体化を同じ表現として扱わないこと。**

## 6. 完成モチーフの構造解析

WorkはT1の生成を開始する前に、添付②を解析する。

### 6.1 解析項目

1. モチーフの全体シルエット
2. 頭部・胴体などの主要構造
3. モチーフ固有の特徴的な部位
4. 各部位の位置・大きさ・接続関係
5. 主要な曲線・輪郭・内部構造
6. モチーフの向き・姿勢・動きの方向
7. 光姫との位置関係
8. 理想鏡ルミアとの光学的な接続関係

### 6.2 モチーフ固有構造の扱い

部位の名称・数・形状は対象モチーフに応じて判断する。

例：

- イルカ：頭部、吻、胴体、背びれ、胸びれ、尾びれなど
- 蝶：頭部、触角、胸部、腹部、翅など
- クラゲ：傘、口腕、触手など

これらは解析方法を説明する例であり、実際の完成形は添付②を優先する。

## 7. 光の骨格形成技術

本章は、クリオネ制作で成功した骨格形成表現をモチーフ共通の制作技術として再利用するための詳細手順である。

特にT5〜T7の演出設計と、T6の画像生成に適用する。

### 7.1 骨格の定義

ここでいう「骨格」とは、実際の生物の解剖学的な骨格ではない。

**完成モチーフの形状を定義する、光の構造線・輪郭・内部フレームの集合を意味する。**

完成モチーフの構造を維持しながら、未完成の光イルミネーションとして描く。

### 7.2 光骨格への変換

完成基準画から抽出した構造を、以下の表現に変換する。

- 外形：細い発光線で輪郭を構築する。
- 主要構造：モチーフの特徴を認識できる光の骨格を形成する。
- 内部構造：必要に応じて光の網目・線・粒子で表現する。
- 未完成部分：輪郭や内部構造を部分的に光粒子へ分解する。
- 透明感：骨格の隙間から背景が透けて見えるようにする。
- 発光：青・紫・ピンク系を基本とし、完成基準画の配色を優先する。

### 7.3 モチーフ固有の変換規則

- 細長い構造：連続する発光線を使用する。
- 面状の構造：輪郭線と内部の発光網目を使用する。
- 厚みのある構造：立体的な曲線と内部光線を使用する。
- 特徴的な部位：完成基準画から形状を継承し、識別できるように描く。

すべてのモチーフに同じ網目模様を機械的に適用してはならない。

対象モチーフの形態に適した光骨格表現を設計する。

### 7.4 T6の形成状態

T6では、次の条件を満たす。

1. モチーフの種類を判別できる主要構造が形成されている。
2. 輪郭と内部構造が光の線として視認できる。
3. 一部の構造はまだ粒子状・透明な未完成状態である。
4. 完成画像の表面質感・発光密度・実体感はまだ成立していない。
5. T7以降に光の肉付けが進む余地が残されている。

### 7.5 禁止する骨格表現

- 完成画像の単純な半透明化
- 完成画像の単純な減光
- 完成画像の縮小のみ
- 完成した実体を先行表示すること
- 完成形と異なる生物構造への変更
- 過剰な白色発光によって骨格構造が見えなくなること
- モチーフ固有の特徴が失われること

### 7.6 T5・T6・T7の連続性

**T5：骨格形成途中**

主要な輪郭・構造線が部分的に現れる。完成形の特徴は見え始めるが、構造全体はまだ成立していない。

**T6：光骨格形成**

主要な輪郭と内部構造が成立し、モチーフを識別できる。透明感と未完成部分を残す。

**T7：実体化開始**

T6の構造を維持しながら、光の面・粒子・発光密度が増す。T6で成立した構造を別形状に描き直してはならない。

## 8. 光姫とルミアの演出設計

### 8.1 Identity Lock

光姫の以下を維持する。

- 顔の骨格・輪郭
- 目・眉・鼻・口の形状と位置関係
- 年齢印象
- 髪型・髪色・髪飾り
- 衣装・装飾・素材感
- 人物全体の同一性

### 8.2 Geometry Lock

以下の不自然な変化を禁止する。

- 頭身の変化
- 顔の縦横比の変化
- 首・肩・胴体の比率の変化
- 腕の長さ・太さの変化
- 手指の本数・形状の異常
- 人物の不自然な移動・回転

### 8.3 ルミアの継承

- 理想鏡ルミアのデザインを維持する。
- 衣装との位置関係を維持する。
- 光の発生源としての役割を明確にする。
- モチーフとの光学的な接続を自然に描く。

### 8.4 人物動作

- 開始画像と終了画像から自然な中間動作を設計する。
- 視線はモチーフの形成に応じて自然に移動させる。
- 腕・手・指の動作は時間的連続性を持たせる。
- 特定のポーズを全モチーフ共通で固定しない。

## 9. カメラ・背景・Rendering

### 9.1 カメラ

- 縦9:16
- 開始・終了画像と連続する画角
- 人物とモチーフの適切な配置
- 人物の大きさと遠近感の維持

### 9.2 背景

- アーチ、照明、床、壁など、入力画像の空間構造を維持する。
- 背景を勝手に別の場所へ変更しない。
- 反射や影の方向をできる限り整合させる。

### 9.3 Rendering

- 入力画像の光学表現・色彩・質感を継承する。
- 光骨格の発光線を明確に描く。
- 光粒子の密度と透明感を時間軸に沿って変化させる。
- 光姫の外見を発光演出によって再デザインしない。

## 10. Work一括制作手順

### STEP 1：入力確認

- T0・T10の2枚を確認する。
- 対象モチーフを特定する。
- 光姫・ルミア・背景・構図を解析する。

### STEP 2：10秒間の演出設計

- T1〜T9の演出内容を決定する。
- T6に光骨格形成を配置する。
- T5以前に完成状態を出さない。
- T7以降に実体化を進める。
- 人物動作と光の進行を整合させる。

### STEP 3：時系列順に画像生成

以下の順序で制作する。

T1 → T2 → T3 → T4 → T5 → T6 → T7 → T8 → T9

T6は第7章の光骨格形成技術を適用する。

T6のみを独立した制作依頼として扱わない。

### STEP 4：各画像の自己点検

各画像の生成後、Work自身が以下を確認する。

- 人物の同一性
- 身体構造
- モチーフの構造
- 発光・透明感
- 前後画像との連続性
- 時間軸上の形成段階

問題があれば修正・再生成を試みる。

### STEP 5：制作継続

各画像の自己点検後、人間の途中承認を要求せず、次の画像生成へ進む。

T6でも特別な承認待ち工程を設けない。

### STEP 6：全体QA

9枚の生成後、T0〜T10を時系列で確認する。

- モチーフが途中で別形状になっていないか。
- 光の形成が逆行していないか。
- T6の骨格形成が成立しているか。
- T7以降に自然な実体化が進んでいるか。
- 人物・背景・構図が不自然に変化していないか。
- T9からT10へ自然につながるか。

### STEP 7：成果物提出

9枚の画像、演出構成、QA結果、再生成履歴をまとめて提出する。

**制作途中で人間の承認を要求することを標準工程に組み込まない。**

ただし、実行環境の制約、画像生成の失敗、参照資料の不足などにより継続不能となった場合は、実際の進捗と未完了事項を報告する。

## 11. 品質保証

### 11.1 個別画像QA

| 検査項目             | 確認内容            |
| ---------------- | --------------- |
| Identity         | 光姫の顔・髪・衣装・装飾    |
| Geometry         | 顔・身体・手指の形状と比率   |
| Motif Structure  | 完成基準画との形状・構造の一致 |
| Formation State  | 指定秒数に適した形成状態    |
| Rendering        | 光線・粒子・透明感・質感    |
| Composition      | 人物・モチーフ・背景の構図   |
| Video Continuity | 前後画像との連続性       |

判定はOK／NG／要確認とする。

### 11.2 全体QA

特に以下を重点検査する。

- T4→T5→T6の骨格形成
- T6→T7→T8の実体化
- T9→T10の完成形への接続
- 光姫の顔・衣装・身体比率の維持
- モチーフの種類・向き・構造の維持

### 11.3 NG対応

NGを検出した場合は、Workが可能な範囲で修正・再生成を試みる。

修正しても解決しない問題は、NGまたは要確認として記録する。

修正未完了の画像を、検査済みの完成画像と偽って報告してはならない。

## 13. 次工程：FlovaAI（Kling）への引き渡し

本仕様書の制作対象は、Workによる中間静止画の生成までとする。

動画生成は別工程で実施する。

次工程では、Workが生成した静止画から必要な開始・終了フレームを選択し、FlovaAI（Kling）で画像間の動画を生成する。

クリオネ制作で検討した例：

- 開始フレーム：T3のルミア発光・形成開始画像
- 終了フレーム：T6の光骨格形成画像
- 目的：光粒子が集まり、対象モチーフの光骨格が形成される過程を動画化する。

このT3→T6の構成は、次工程の利用例であり、WorkがT1〜T9を制作する義務を省略するものではない。

FlovaAI（Kling）のモデル別設定、動画尺、プロンプト、品質検査は別仕様書で定義する。

## 14. 制作標準の改善管理

### 14.1 成功事例

クリオネ制作において、光の輪郭・内部構造・粒子・透明感を組み合わせた骨格形成画像が得られた。

この表現を、今後のモチーフに応用する。

### 14.2 確認された課題

過去のクリオネ制作では、完成に近いモチーフが先に現れ、その後に未完成の骨格へ戻る時間的逆行が発生した。

### 14.3 今回の改善策

- 10秒全体の演出を先に設計する。
- T6の骨格形成を標準演出として定義する。
- T5以前の完成形先行表示を禁止する。
- T7以降に実体化を進める。
- 9枚を時系列順に生成する。
- 各画像と全体の連続性をWorkが検査する。
- 途中承認なしで一括制作を進める。

### 14.4 未検証事項

- 異なるモチーフへの骨格形成技術の再現性
- 9枚の一括生成における人物同一性の安定度
- Workによる自己点検・再生成の有効性
- T3→T6などの静止画ペアを使った動画生成の連続性

これらは実制作で検証し、結果を次版へ反映する。

## 15. ChatGPT Workへの一括制作依頼文

以下を実制作時の依頼文として使用する。

### ROLE

あなたは『竜宮プロトコル創世記』の公式キャラクタービジュアル制作アシスタントです。

3. T1〜T9を時系列順に生成する。
4. 各画像の自己点検と必要な再生成を試みる。
5. 人間の途中承認を求めず、制作を継続する。
6. 全9枚の連続性を確認する。
7. 画像とQAレポートを一括提出する。

- 完成状態の早出しを禁止する。
- 形成進行度の逆行を禁止する。
- T6を独立制作依頼にしない。
- 人間の途中承認を標準工程にしない。
